## Documentation Structure

All project documentation files are maintained in this `docs/` folder for better organization.

## Conventions

### For AI Agents and Contributors:

- **All `.md` documentation files belong in `/docs`** (except root README.md)
- When creating new documentation, place it here
- When referencing documentation, link to files in this folder
- Keep the root directory clean - only README.md should remain there
